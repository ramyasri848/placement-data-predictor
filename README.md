# Placement Data Predictor

A Python-based mini project that analyzes student placement data and predicts placement chances through an interactive web application.

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Streamlit

## Features

* Editable student dataset
* Dynamic data analysis
* Real-time graph updates
* Placement statistics
* Placement prediction system
* Interactive web application

## Project Structure

placement-data-predictor/
│
├── dataset/
├── graphs/
├── src/
├── app.py
├── main.py
├── requirements.txt
└── README.md

## Libraries Used

### NumPy

Used for:

* Average CGPA calculation
* Highest DSA score calculation

### Pandas

Used for:

* Reading CSV dataset
* Editable tables
* Filtering placed and non-placed students
* Data analysis

### Matplotlib

Used for:

* CGPA bar graph
* DSA score line graph
* Placement distribution pie chart

### Streamlit

Used for:

* Creating interactive web application
* Editable dataset interface
* Dynamic graph updates
* User input forms
* Real-time placement prediction

## Graphs Generated

* CGPA Bar Graph
* DSA Score Line Graph
* Placement Pie Chart

## How to Run

Install required libraries:

pip install -r requirements.txt

Run the Streamlit web app:

streamlit run app.py
